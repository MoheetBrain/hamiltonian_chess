# `research/audit/` — V7 Total Forensic Audit working files

Nine independent auditors (`a1`…`a9`), each briefed to **destroy** the V7 experimental argument
rather than defend it, plus integrator verification under `integrator/`.

Read the verdict in **`docs/V7_TOTAL_FORENSIC_AUDIT.md`**. These are the working files behind it.

## Reproducing

All scripts are CPU-only, offline, and make **no model call**. Run from the worktree root with the
shared venv, always via `python -m`:

```bash
python -m research.audit.integrator.verify_audited_string
```

The DEV probe bank rebuilds bit-exact (`dev_pool_hash = f804e0d9…`, matching the frozen V7
artifact), so every number here is on the exact bank V7 ran.

## Deliberately not committed

Three large intermediates are regenerated by their own scripts and are excluded to keep the tree
small:

| file | size | regenerated by |
|---|---|---|
| `a2_covariates/probe_covariates.jsonl` | 2.4 MB | `a2_covariates/` scripts |
| `a3_shortcuts/bank_features.jsonl` | 587 KB | `a3_shortcuts/` scripts |
| `a5_sel/a5_rows_annotated.json` | 531 KB | `a5_sel/` scripts |

Every *summary* artifact each of them feeds — the predictability matrix, the shortcut tables, the
error taxonomy — **is** committed.

## Status of these numbers

They are **diagnostics of the instrument**. None of them may be used to re-score V7, to promote any
candidate, or to reinterpret a recorded sentinel. Where an auditor reasoned rather than measured,
the report labels it HYPOTHESIS.
