# Decision Log

## 2026-09-05 — Isolate the Arena

The GitHub repository was empty, so the Arena was built as a new package on
`codex/arena-v0`. Legacy HML and corpus repositories were inspected read-only. Their failing
tests and distinct truth models prevent direct dependency reuse.

## 2026-09-05 — Canonical truth is immutable

Candidate languages are reversible views over a typed canonical record. Mathematical hashes
exclude runtime metadata. Schema-changing mutations require an explicit governance path.

## 2026-09-05 — Synthetic Gold is narrowly labelled

Gold requires native acceptance and a second deterministic domain-template certificate.
Template independence is code-path independence, not proof of broad mathematical validity.

## 2026-09-05 — Preserve unmeasured values

The dashboard uses `UNMEASURED` for model metrics. Byte-derived token proxies are labelled as
proxies. No synthetic value is substituted for next-action or OOD performance.

## 2026-09-05 — Do not freeze on static compactness

The compact symbolic seed may dominate the static byte proxy while all candidates have perfect
roundtrip. That does not establish learnability. R*-V0 remains blocked pending matched
adaptation against strong controls.
