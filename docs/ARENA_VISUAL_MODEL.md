# Arena Visual Model

The future interface is a projection of the scientific event log, not a second game engine.

## Layers

0. **Mathematical reality:** immutable canonical states, transitions, oracle records, and
   verifier evidence.
1. **Representation genome board:** each living candidate occupies a lineage/Pareto niche;
   its surface and content genes are visible pieces.
2. **Architect moves:** a typed one-gene mutation, crossover, new family, corpus request, or
   instrument request enters the build queue.
3. **Semantic/adversarial survival:** compilers face roundtrip, information-accounting,
   side-channel, verifier, fuzz, and Refuter gates. Critical failure removes the candidate.
4. **Solver mathematical play:** surviving views face frozen task families; answers, swaps,
   counterfactual flips, costs, and verified actions become match events.
5. **League/evolution:** paired outcomes update promotion, niches, Pareto archive, Hall of Fame,
   retirement, and the next generation.
6. **R* training-data factory:** only a released champion renders verified trajectories for
   matched learning and scaled data generation.

## Exact game terms

- **Board state:** one immutable event-log snapshot containing canonical corpus version,
  instrument freeze, population, lineage, budgets, failures, and league tables.
- **Piece:** one content-addressed `ModelViewGenome` plus deterministic compiler.
- **Move:** one typed proposal whose resulting semantic/view delta is recorded.
- **Match:** paired evaluation of candidates on identical frozen canonical tasks and targets.
- **Round:** one fidelity tier over a declared roster and task slice.
- **Generation:** children created from the population frozen at the previous generation end.
- **Win:** a preregistered paired statistical/gate success, never raw-score rank alone.
- **Elimination:** semantic death, critical exploit, budget rule, or preregistered league loss.
- **Promotion:** authorization to enter the next fresh tier; it is not release.
- **Champion:** current Pareto/Hall-of-Fame leader with surviving evidence and uncertainty.
- **R* release:** immutable representation/protocol artifact that passes hidden, OOD, matched
  learning, assurance, reproducibility, and documentation gates.

No animation or UI is built in Phase 3. Any later display must be reproducible from actual
events and must distinguish proposal, measurement, inference, and release.
