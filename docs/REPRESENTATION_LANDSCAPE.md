# Representation Landscape: Invalid V3 Scout

This is a diagnostic landscape, not fitness evidence.

Across the eight equal-information founders, seven produced exactly the same outcome vector:
all ten non-delta positive variants correct and both delta positives malformed/incorrect.
Compact symbolic alone answered the two delta positives and their swaps correctly. That gives
a visible local behavior difference but only two discordant paired wins, p=.25, and it fails
the preregistered minimum and Holm correction.

The content mini-family provides negative engineering evidence. Adding the complete auditable
projection block did not improve JSON. Explicit dependency edges lost both obligation-owner
positives; target blocks additionally lost premise/ownership positives and had only 50% valid
responses. Delta-plus-context was byte-for-byte behaviorally tied with the Track C baseline.

Likely mechanisms, not conclusions:

- compact symbolic uses fewer prompt tokens on most families and may leave more effective
  attention/completion capacity for the two-state delta task;
- Track C currently places the full witness/accounting ledger in the model prompt, increasing
  mean prompt length and distracting the solver;
- the external ledger should remain hash-bound audit evidence while a smaller derived view is
  shown to the model;
- future DEV selection must gate every mechanism (or a prespecified hierarchical mixture), not
  only aggregate accuracy.

Because the only favorable edge is two trials on a single mechanism and the instrument is
bimodal, neither `REPRESENTATION_SIGNAL_FOUND` nor
`NO_MEASURABLE_REPRESENTATION_SIGNAL` is justified. The experiment is invalid.
